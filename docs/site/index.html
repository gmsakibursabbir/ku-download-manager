Downloads, without the waiting.

A lightweight download manager for Windows, macOS and Linux. Multi-connection downloads that resume after anything, a browser extension that hands files over, and video downloads from thousands of sites.

Everything a download manager should do

Built on a native Rust core with our own adaptive HTTP engine, aria2 for torrents and FTP, and yt-dlp for media.

Adaptive speed

KuHTTP opens more connections while it pays off and backs off when a server objects — 1.5–2.6× faster than aria2 in our benchmarks.

Resume after anything

Pause, lose Wi-Fi, reboot or crash: downloads continue from the last byte written to disk.

Browser takeover

Downloads you click in the browser open a small “Download File” window — even when the app is in the tray.

Video downloads

A KuDownload button on videos on any site, with quality choice, playlists, audio-only and subtitles.

Queues & schedules

Run queues at night, limit speed with profiles, shut down when done, and sync files that changed on the server.

Knows the tricks

Google Drive, Dropbox and SourceForge links become direct downloads; duplicates are caught before they start.

Progress window

Per-download window with speed, time left, and a live map of every connection.

Private by design

No accounts, no telemetry. The browser extension talks only to the app on your computer.

Feels at home on your desktop

Native window controls on Windows, macOS, GNOME, KDE, Cinnamon, XFCE and tiling compositors like niri and Hyprland. Light, dark, eight accent colours, English and বাংলা.

Questions

Is it really free?

Yes. No ads, no accounts, no paid tier. The source code is on GitHub.

Where do yt-dlp and FFmpeg come from?

The first time you download a video, KuDownloader offers to download them from their official GitHub releases and checks each file against the publisher’s SHA-256 list.

Does it collect any data?

No. See the privacy policy.

Can it download DRM-protected video?

No. Protected streams are detected and refused.
